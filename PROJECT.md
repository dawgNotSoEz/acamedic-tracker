# CyberSprint

A study tracking platform for cybersecurity, blockchain, DSA and software engineering.

## Features

### Dashboard
- Today's tasks
- Study streak
- Hours studied today
- Weekly progress
- Monthly progress

### Roadmaps
- Create study plans
- Weeks
- Days
- Tasks

### Resources
- Store links
- Categorize resources

### Study Sessions
- Start timer
- Pause timer
- End timer

### Analytics
- Topic-wise hours
- Completion percentages

## Tech Stack

Frontend:
- Next.js
- TypeScript
- Tailwind

Backend:
- Next.js API

Database:
- PostgreSQL

ORM:
- Prisma

Auth:
- NextAuth
